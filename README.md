# Evaluación de Cultura Organizacional

Aplicación para la evaluación de la cultura organizacional en empresas con más de 20 años de trayectoria.

## Descripción

El proyecto busca convertir un instrumento de evaluación desarrollado por un equipo de investigación en una aplicación que permita a las empresas realizar una evaluación de su cultura organizacional, obtener sus resultados y consultar recomendaciones y su evolución a través del tiempo.

## Estructura del proyecto

- `docs/`: documentación del proyecto.
- `frontend/`: interfaz de usuario y mockups.
- `backend/`: lógica y procesamiento de la aplicación.
- `database/`: elementos relacionados con el almacenamiento.
- `tests/`: pruebas del sistema.
- `entregables/`: entregables correspondientes a cada semana.
